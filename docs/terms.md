# 利用規約

制定日：2026年9月28日

この利用規約（以下「本規約」といいます）は、Ryuya Onishi（以下「当方」といいます）が提供するアプリケーション「ヒストラリ」（以下「本アプリ」といいます）の利用条件を定めるものです。ユーザーは、本規約に同意の上、本アプリをご利用いただくものとします。

## 第1条（適用）

本規約は、ユーザーと当方との間の本アプリの利用に関わる一切の関係に適用されます。

## 第2条（サービスの内容）

1. 本アプリは、ユーザーが日々の記録（日記、写真、鑑賞・視聴したコンテンツの記録等）を保存し、後から振り返ることができる記録アプリです。
2. 本アプリには、記録内容を基に文書（PDF形式の「本」）を生成する機能を含みます。
3. 本アプリには、無料で利用できる機能と、有料のサブスクリプション（以下「プレミアム」といいます）に加入することで利用できる機能があります。
4. 本アプリで記録したデータは、ユーザーの端末内に保存されます。端末の故障・紛失や本アプリの削除によりデータが失われた場合、当方はデータを復元することができません。

## 第3条（本アプリの性質に関する重要事項）

1. 本アプリで作成される記録・文書は、あくまでユーザー個人の記録・メッセージであり、遺言その他法的効力を有する文書ではありません。法的に有効な遺言の作成をご希望の場合は、弁護士・行政書士・公証役場等の専門家にご相談ください。
2. ユーザーが本アプリに登録する緊急連絡先情報の正確性・最新性は、ユーザーご自身の責任で管理いただくものとします。当方は、緊急連絡先への通知等を代行する機能を提供していません。

## 第4条（利用対象）

本アプリの利用対象は13歳以上とします。13歳未満の方の記録を残したい場合は、保護者の方がご自身の端末でご利用ください。

## 第5条（禁止事項）

1. 法令または公序良俗に違反する行為
2. 当方または第三者の知的財産権、肖像権、プライバシー権その他の権利を侵害する行為
3. 本アプリの運営を妨害する行為、不正アクセスその他システムに過度な負荷をかける行為
4. 本アプリに登録した他者の情報（緊急連絡先として登録した第三者の情報等）を、本人の同意なく目的外に利用する行為
5. その他、当方が不適切と判断する行為

1. プレミアムの購入・決済は、Apple社が提供する App Store の課金システムを通じて行われます。料金は購入画面に表示される金額とし、購入の確定時にApple IDのアカウントに請求されます。
2. 無料トライアルが提供される場合、トライアル期間の終了までに解約しない限り、自動的に有料のサブスクリプションへ移行します。
3. サブスクリプションは、現在の期間が終了する24時間前までに自動更新をオフにしない限り、同じ期間・料金で自動的に更新されます。更新料金は、期間終了前の24時間以内に請求されます。
4. 解約や自動更新の停止は、端末の「設定」＞［ユーザー名］＞「サブスクリプション」から行えます。
5. 返金は Apple社の定める手続きに従うものとし、当方では返金処理を行うことができません。
6. 当方は、サブスクリプションの価格を変更することがあります。価格変更時は、Appleの定める方法に基づき事前にお知らせします。
